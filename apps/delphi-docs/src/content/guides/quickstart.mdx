Every model in delphi.ai is a `DelphiModel`: a `torch.nn.Module` that also
says how it is trained. You write the parameters, `forward` and the loss; one
trainer runs the optimization, records every iterate, and reports estimates at
several of them. The models in this library, from truncated distributions to
regressions, are built the same way.

## Write a model

A model that estimates the median of a sample, as the value minimizing the
mean absolute error:

```python
import torch as ch
import torch.utils.data

import delphi.delphi
import delphi.trainer
from delphi.configs import base


class Median(delphi.delphi.DelphiModel[base.DelphiConfig]):
    """The median of a sample: the minimizer of the mean absolute error."""

    # The pydantic config hyperparameters are validated against.
    defaults = base.DelphiConfig

    def __init__(self, *, hyperparameters=None):
        super().__init__(hyperparameters=hyperparameters)
        self.median = ch.nn.Parameter(ch.zeros(1))
        # The loss the trainer minimizes: criterion(model(x), y).
        self.criterion = self.absolute_error

    def forward(self, x):
        return self.median.expand(x.size(0))

    @staticmethod
    def absolute_error(prediction, target):
        return (prediction - target).abs().mean()
```

## Train it

Hand the model and its validated hyperparameters to the trainer, with a
training and a validation loader:

```python
ch.manual_seed(0)
samples = ch.distributions.Exponential(1.0).sample([2000])
loader = torch.utils.data.DataLoader(
    torch.utils.data.TensorDataset(ch.zeros(2000, 1), samples), batch_size=100
)

model = Median(
    hyperparameters={"iterations": 2000, "lr": 0.05, "record_params_every": 1}
)
procedure = delphi.trainer.Trainer(model, model.hyperparameters).train_model(
    loader, loader
)
```

## Read the estimates

`train_model` returns the whole procedure; its last phase holds the iterates
and the estimates computed from them:

```python
run = procedure.phases[-1]
run.avg_params    # tensor([0.6937]): mean of the iterates after the burn-in
run.final_params  # tensor([0.6970]): the last iterate
run.stop_reason   # "max_iterations"
```

The sample median is 0.6931. The averaged iterate is the one to read: the
last iterate still moves with each batch.

## Truncated in one minute

The library's first area is truncated statistics: samples missing everything
outside a set. Its models wrap the trainer behind `fit`. Here, a correlated
Gaussian observed only where $x_0 + x_1 > 1$:

```python
import torch.distributions

from delphi.truncated.distributions import truncated_multivariate_normal

ch.manual_seed(0)
population = torch.distributions.MultivariateNormal(
    ch.zeros(2), ch.tensor([[1.0, 0.5], [0.5, 1.0]])
).sample([100000])


def phi(x):  # the truncation set: what is ever observed
    return x.sum(dim=-1) > 1.0


S = population[phi(population)][:10000]

# Fit on standardized data, moving phi through the same transform.
mean, std = S.mean(0), S.std(0)
model = truncated_multivariate_normal.TruncatedMultivariateNormal(
    phi=lambda z: phi(z * std + mean), alpha=phi(population).float().mean().item()
)
model.fit((S - mean) / std)

recovered_loc = model.avg_loc_ * std + mean
recovered_cov = ch.diag(std) @ model.avg_covariance_matrix_ @ ch.diag(std)
```
